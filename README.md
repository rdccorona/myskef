# Myskef

Play Windows games (Epic Games, Steam, or any `.exe`) on a Mac, for free.

**Download:** grab `Myskef.zip` (and `Read-me-first.txt`) from the latest release on the
[Releases page](https://github.com/rdccorona/myskef/releases/latest). Unzip, move Myskef to Applications, open it.
macOS will block it the first time because it isn't from a registered developer:
on macOS 15 open **System Settings → Privacy & Security → Open Anyway**.

After that, Myskef updates itself: it shows a banner when a new version is out.

Built on free software: Wine (LGPL), Gcenx's macOS Wine builds, DXVK (zlib), DXMT (LGPL),
MoltenVK (Apache 2.0), legendary (GPL-3.0), and optionally Apple's D3DMetal (Apple's licence),
all downloaded from their official sources when needed. Not affiliated with Apple, Epic Games,
Valve or any game studio. You need to own the games you play.
